## التحقق من المحتوى

الملفان الأصليان PDF وTXT خاصان، ولذلك لا يتم تضمينهما في النسخة العامة أو مستودع GitHub.

- عند توفر المصدرين محلياً داخل `verification/sources/` يمكن تشغيل التحقق الحرفي الكامل:

```bash
node scripts/verify-biology-chapter-03.mjs --mode=local
```

- النسخة العامة تستخدم قفل المصدر الموثّق وفحص سلامة الإصدار:

```bash
node scripts/verify-public-release.mjs
```

يمنع رفع صور الطلاب إلى الشبكة؛ تبقى الصور على جهاز المستخدم داخل المتصفح.


## النشر على GitHub Pages

يتضمن المشروع Workflow جاهزاً داخل `.github/workflows/deploy-pages.yml`. بعد رفع المشروع إلى مستودع GitHub وتشغيل Pages عبر GitHub Actions، ينفذ تلقائياً فحص سلامة الإصدار، وLint، واختبارات Playwright، ثم البناء والنشر.

الأيقونات مدمجة محلياً ضمن البناء ولا يعتمد التطبيق على CDN خارجي.
